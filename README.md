# About This Mixin

[![Unit Tests](https://github.com/logstash-plugins/logstash-mixin-rabbitmq_connection/actions/workflows/unit-tests.yml/badge.svg?branch=main)](https://github.com/logstash-plugins/logstash-mixin-rabbitmq_connection/actions/workflows/unit-tests.yml)

This is a mixin supporting  the logstash rabbitmq inputs and outputs. If you plan on writing a logstash plugin using
rabbitmq this may be useful.
